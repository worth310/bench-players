# Bench Players

An installable football substitution manager for Under-13 9-a-side matches.

## Publish with GitHub Pages

1. Create a public GitHub repository called `bench-players`.
2. Upload every file in this folder to the top level of that repository.
3. In the repository, open **Settings** → **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then press **Save**.
6. After GitHub has finished publishing, open `https://worth310.github.io/bench-players/`.

On an iPhone, open that address in Safari, choose **Share**, then **Add to Home Screen**. On Android, open it in Chrome and select **Install app**.
